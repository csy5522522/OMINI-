# Omini工具箱

Windows 桌面工具箱。包含下载中心、校园网、课表、备忘录、Bright Data 和多电脑文件夹同步。

当前版本 **1.1.2**：[下载 Windows 安装包](https://github.com/csy5522522/OMINI-/releases/tag/v1.1.2)。下载 `Omini-Toolbox-1.1.2-Setup.exe` 后运行安装向导，无需单独复制程序依赖。更新内容见 [CHANGELOG.md](CHANGELOG.md)。

## 新增 Web 版（下载中心 + 学校课表）

双击源码根目录的 `Start-Omini-Web.cmd`，或运行 `python web_server.py --open`，在浏览器打开 `http://127.0.0.1:18765`。提供重新设计的深浅主题界面、下载队列与文件取回、学校课表导入和周视图。需使用源码运行环境与下载引擎；1.1.2 桌面安装包不包含此新增入口。

支持绑定本机 Tailscale IPv4 后从其他组网设备访问，下载仍由服务电脑处理。Web 队列与课表独立保存。启动参数、远程访问密码和课表导入方法见 [Web 版使用说明](web/README.md)。

## 检查与安装更新

进入「设置 → 软件更新」，点击「检查更新」。程序从 `csy5522522/OMINI-` 的 GitHub 最新正式 Release 比较版本，发现新版后启用「下载更新」。下载支持进度和取消，完成后校验文件大小与 SHA-256；校验通过后点击「退出并安装更新」。工具箱完成下载任务处理、保存和后台服务退出后才启动安装向导。安装器沿用原安装位置，保留个人设置和同步数据。

仓库为私有时，每台电脑需要填写有权访问该仓库的 GitHub Token。建议使用仅选择此仓库、Contents 为只读的细粒度 Token；公开仓库可以留空。可勾选 Windows 本机加密保存；取消勾选并保存会移除已保存 Token。凭据只用于 GitHub API，下载跳转到 GitHub 文件分发域名时不转发 Token，安装包不内置账号凭据。

更新配置位于 `%APPDATA%/Omini工具箱/updates/credentials.json`，安装包缓存位于同目录的 `downloads/版本号/`。下载安装前均校验文件完整性，不自动安装较旧版本、预览版或缺少校验信息的附件。更新源使用 [GitHub Releases API](https://docs.github.com/en/rest/releases/releases#get-the-latest-release)。

从旧版首次升级到带此按钮的 1.1.2，请先手动运行一次新安装包；之后可在程序内检查和下载安装后续版本。测试：`python -m unittest tests.test_updater -v`。

## 本地运行

```powershell
py -3.11 -m pip install -r requirements.txt
py -3.11 app.py
```

开发环境下，应用会优先从 `tools/` 查找下载引擎，找不到时使用 PATH 中的 `yt-dlp`、`aria2c`、`ffmpeg`、`gallery-dl`、`spotdl`。

## 打包

### Windows 安装版

发布安装包位于 `dist-installer-1.1.2/Omini工具箱-1.1.2-Setup.exe`。双击运行中文安装向导，可选择安装目录并创建桌面 / 开始菜单快捷方式；完整依赖和同步引擎自动安装。

默认安装到当前用户的 `%LOCALAPPDATA%/Programs/Omini工具箱/`，无需管理员权限。可从 Windows「已安装的应用」或开始菜单卸载。卸载保留 `%APPDATA%/Omini工具箱/` 中的个人设置、设备身份，以及同步目录中的文件。升级前从托盘退出工具箱，再运行新安装包。

已有完整 `dist-sync-1.1.2/Omini工具箱/` 发布目录时，使用 Inno Setup 6.7.3+ 执行 `./scripts/build_installer.ps1` 生成安装包；也可用 `-Compiler` 指定 `ISCC.exe` 路径。

### 开发用目录发布包

```powershell
./build.ps1
```

发布结果在 `dist/Omini工具箱/`。请保留该目录中的 `Omini工具箱.exe`、`_internal/` 与 `tools/`，不要单独移动 EXE。当前源码版本为 `1.1.2`。

`build.ps1` 会下载 yt-dlp 的官方 Windows 发行版、复制本机的 aria2c/ffmpeg，并将图库和 Spotify 引擎打成独立的 Windows 可执行文件。
应用窗口、托盘、侧栏品牌及 EXE 均使用 `assets/` 中的 Omini 图标；打包时会一并收集图标资源。

M3U8 页签通过 yt-dlp 的 HLS 原生分片下载器获取播放列表，支持并发下载与分片重试，并由 ffmpeg 合并为 MP4。文件名可以留空自动生成，或手动填写。

抖音公开视频由随包的 `tools/yt-dlp-plugins/omini/` 解析器优先读取公开移动分享页，再交给 yt-dlp 下载、嵌入封面与元数据。普通公开视频通常无需 Cookie；分享页未提供视频时才回到原接口并按需提示登录或验证。

支持手动选择 Netscape cookies.txt 或 `name=value;` Cookie 请求头文本（包含 `Cookie:` 前缀也可）。请求头在任务期间临时转换，结束后删除临时文件。Chrome/Edge 会话只在用户主动点击对应按钮时读取。

发布包必须保留 `tools/yt-dlp-plugins/`，否则抖音会退回原解析路径。窗口标题显示版本 `1.1.2`，便于与旧发布包区分。

支持抖音 `/note/` 图文分享链接：在视频页或图库页粘贴即可识别，下载全部公开图片，队列显示为“图文”；图文不伪装为 MP4。公开分享页缺少图片时打开临时、内存会话的浏览器解析窗口；页面如有登录或验证需由用户完成，再点击“重新解析已加载图片”。不读取已有浏览器登录数据库，不保存该窗口的 Cookie。浏览器回退仅用于公开图文图片，不下载评论表情、头像或推荐封面。

新任务自动置顶、选中并显示实时日志；完成后会提示保存目录。“清空队列”一次停止全部在途任务、移除全部队列记录，保留下载文件和日志。清空前的记录自动备份到 `%APPDATA%/Omini工具箱/queue-backups/`；应用下次启动不会重新加载已清空记录。

按钮回归测试：`py -3.11 -m unittest tests.test_queue -v`。测试使用隔离的临时队列，不修改用户记录。

## 校园网自动登录

打开侧边栏「校园网自动登录」，填写账号和密码并点击「保存配置」。校园网页地址支持 `http://10.24.127.3/eportal/success.jsp?userIndex=...&keepaliveInterval=0`，也支持完整登录页地址；新配置默认指向 `success.jsp`，目标 Wi-Fi 为 `LEDE1`，服务名称按当前抓包留空。

「打开校园网页」优先打开当前会话的登录成功页。填写成功页完整地址后，程序先检查其中的会话是否在线；会话过期时重新获取当前连接的认证参数并登录，成功页随后使用新返回的 `userIndex`。浏览器在点击按钮时打开。

- 「立即登录」检查当前网络，已连通时跳过重复认证。
- 「连接目标 Wi-Fi 后自动登录」在应用启动及重新连接 LEDE1 时触发，每 10 秒检测一次；连接其他 Wi-Fi 时不发起认证。
- 「间隔定时」可设置 1～1440 分钟，默认 30 分钟；「每天定时」按本机时间每天触发一次。休眠或断网期间错过的任务在应用恢复且连接目标 Wi-Fi 后补检。
- 登录失败后间隔 60 秒重试，连续失败 3 次后暂停本轮自动尝试，重新连接目标 Wi-Fi 或保存配置可重新触发。
- 勾选「使用 Windows 本机加密保存密码」后，密码通过 DPAPI 加密存入配置；取消勾选并保存会删除已保存的加密密码。未保存的密码仅供本次应用运行使用。
- 勾选「关闭窗口后保留在系统托盘」可继续后台检测，双击托盘恢复窗口，右键选择「退出工具箱」结束。后台检测需要应用保持运行；本版不创建开机启动或系统计划任务。

每次认证获取当前连接的重定向参数和页面公钥，按校园网前端的 MAC 拼接、RSA 加密与二次编码流程提交。HAR 仅作为协议参考，未导入其中的密码或旧认证参数。若门户要求验证码，可点击「打开校园网页」。日志仅保留在内存中。

发布目录由 `./build.ps1` 生成到 `dist/Omini工具箱/`，请保留完整目录运行。功能回归：`py -3.11 -m unittest tests.test_class_timetable tests.test_douyin tests.test_timetable tests.test_campus tests.test_queue -v`。校园网测试使用隔离配置与本地模拟 HTTP 服务，并与 `verification/portal-security.js` 中门户原始 RSA 实现比对。

## 学校课表

侧边栏「学校课表」接入广州华立学院教务系统：`https://jw.hualixy.edu.cn/jwglxt/kbcx/xskbcx_cxXskbcxIndex.html?gnmkdm=N2151&layout=default`。

- 点击「导入 HAR」，选择浏览器在查询学生课表后导出的 `.har` 文件。程序读取最新一次有效课表响应，以及同学期同校区的节次时间；支持 Base64 编码的响应。导入后的课表可离线查看，应用重启后自动恢复。
- 点击「登录并读取」，从学校统一身份认证入口 `https://sso.hualixy.edu.cn/heer_cas/#/login?service=https%3A%2F%2Fjw.hualixy.edu.cn%2Fsso%2Fddlogin` 完成登录。学校回调返回教务首页后，自动跳转学生课表页面；确认课表页面和教务会话就绪后，自动抓取选定学年、学期的课程、保存本地缓存并更新界面，无需再次点击读取。也可点击「进入课表」手动打开；「统一认证登录」可重新打开统一入口。窗口使用临时浏览器会话；密码由学校页面处理。统一认证专属 Cookie 不会作为教务课表接口的登录头发送。
- 点击「在线刷新」使用本次会话查询选定学期。会话过期时重新登录；刷新失败时保留已有本地课表。「打开教务网页」打开外部浏览器，外部浏览器登录与内置登录窗口的会话各自独立。
- 选择「全学期」或指定周次查看彩色周课表与课程列表。支持不连续周次、单周和双周；双击周课表中的课程查看教师、教室、校区、周次、学分和教学班。相同时间的多条安排合并显示。
- 勾选「设置第一周周一」，填写学校实际第一周的周一日期并保存，即可用「本周」定位，页面同时显示今日课程。HAR 未提供开学日期时不自动猜测；换学期读取后需要重新设置日期。
- 「会话设置」可手动粘贴 Cookie 请求头，或勾选「使用 Windows 本机加密保存会话」后保存。默认只在本次运行保留会话；加密保存使用 Windows DPAPI，取消勾选并保存会删除已保存会话。Cookie 只用于学校 HTTPS 课表接口，跨域或 HTTP 重定向会终止请求。

课表缓存位于 `%APPDATA%/Omini工具箱/school-timetable.json`，只保留显示课程所需的字段，不存放学号、学生姓名、原始 HAR 或原始登录头。发布包不包含个人课表。测试覆盖周次解析、会话边界、离线恢复、周次切换、内置浏览器临时会话，以及课表线程运行期间退出。

### 班级课表查询

点击「查询班级课表」，或进入「班级课表」标签后点击「打开班级查询」。工具箱内置学校班级查询页面：`https://jw.hualixy.edu.cn/jwglxt/kbdy/bjkbdy_cxBjkbdyIndex.html?gnmkdm=N214505&layout=default`。

学校页面提供学年、学期、校区、年级、学院、专业、专业方向、班级和层次筛选。选择条件后点击学校页面的「查询」，再点击课表名称打开预览。弹出的预览在工具箱内部的新标签打开，可关闭预览或点击「返回查询」继续选择其他班级。学校的 PDF 导出会弹出本地保存对话框。

班级查询和个人课表共用本次应用运行的临时浏览器会话。已在内置窗口登录时可继续查询班级；会话过期时，自动打开统一认证入口，登录返回教务首页后自动进入班级查询。学校页面决定当前账号开放的班级、筛选项和查询结果。班级查询需联网，在学校原生页面中查看与导出；个人课表的本地周视图缓存单独保留。

测试覆盖共享会话、登录回调、预览标签、真实浏览器的本地模拟 PDF 下载及取消导出；发布包不包含班级资料或账号会话。

## iCloud 备忘录

侧栏「iCloud 备忘录」提供两个标签：

- **官方在线**：点击「打开 iCloud 备忘录」，在内置官方页面完成 Apple 账户登录后使用云端编辑与同步。使用独立临时浏览器会话，退出工具箱后清除会话；也可点击「在浏览器打开」。网络、二次验证和设备确认由官方页面处理。
- **本地副本**：点击「导入 HAR 本地副本」选择浏览备忘录时导出的 HAR，提取文件夹、标题、摘要、置顶状态与已捕获的正文。支持 zlib/gzip 压缩的 Notes protobuf 正文和 Base64 HAR 响应。文件中只有摘要的条目明确标记「仅摘要」；锁定笔记只显示标题，需在官方页面解锁。附件、表格、富文本格式未导入，正文按纯文本查看。

本地副本支持搜索、新建笔记 / 文件夹、编辑自动保存、置顶、移到最近删除、恢复与导出文本。搜索作用于当前文件夹；选择「所有备忘录」搜索所有正常笔记。再次导入保留已在本地编辑的条目，也保留较早 HAR 中已捕获的完整正文。本地修改独立保存，不会推送到 iCloud；云端修改请在「官方在线」进行。

缓存保存在 `%APPDATA%/Omini工具箱/icloud-notes.json`，使用当前 Windows 用户的 DPAPI 加密，原子写入。缓存不存原始 HAR、Cookie、登录头或账户信息，发布包不包含个人备忘录。请用原 Windows 账号打开已有缓存；迁移时可手动导出需要的笔记文本。

功能回归：`py -3.11 -m unittest tests.test_icloud_notes -v`，覆盖正文解码、增量响应合并、锁定笔记、加密重启恢复、本地编辑保留、搜索 / 删除 / 恢复、导入线程、浏览器会话和主题按钮。

## Bright Data 数据工具

侧栏「Bright Data」提供独立按钮式工具。顶部「Token」输入框填写个人 MCP 链接中 `token=` 后面的值，也支持粘贴完整 MCP 地址；点击「保存连接」后「测试连接」。旧版保存的链接自动恢复为 Token，默认隐藏并加密保存。

- 「网页搜索」选择 Google、Bing 或 Yandex，输入关键词并点击搜索。每行一个关键词时自动批量搜索，最多 10 条；可选填两位国家代码。单条搜索支持分页标记及服务返回标记时的「下一页」。
- 「网页抓取」输入网页 URL 并点击抓取，返回 Markdown 正文。每行一个 URL 时自动批量抓取，最多 10 条。
- 「采集器」按网站或数据类型查找预建采集器、刷新目录。选择采集方式并「读取参数」后，按动态表单填写输入；支持示例、加入批次及高级 JSON 输入。发现式采集可设置每个输入返回 1～1000 条记录，按返回记录计费。
- 「采集任务」保存返回的任务 ID，可查询进度、获取结果、恢复已有任务。勾选自动更新时每 10 秒查询当前选中且运行中的任务，完成后获取结果。暂停自动更新或退出工具箱会停止轮询；任务 ID 保留在本地。
- 「使用帮助」通过按钮查询 Bright Data 官方支持说明，支持可选参考查询 ID。
- 结果支持文本及表格视图、复制、Markdown / TXT / JSON / CSV 导出。表格最多预览 300 条，导出保留完整记录；表格中的地址双击后填入网页抓取页。网络请求在后台运行。

连接地址使用 Windows DPAPI 加密存入 `%APPDATA%/Omini工具箱/brightdata.json`，随本机用户配置保留。发布包不包含个人 Token。Bright Data 请求使用所配置账户的服务配额。

任务索引保存在同目录的 `brightdata-tasks.json`，仅包含任务 ID、采集器、采集方式、状态和时间。当前界面覆盖已验证账户提供的 11 个 MCP 工具，具体可用工具和配额由所填 Token 对应的账户决定。

回归验证：`py -3.11 -m unittest tests.test_brightdata -v`。

## 多电脑文件夹同步

侧栏「文件夹同步」管理本机身份、其他电脑和共享目录，内置官方 [Syncthing](https://syncthing.net/) `v2.1.6` 引擎。设备间连接使用证书加密；文件按块传输，支持断线续传、中文路径、多电脑共享和冲突副本。

### 首次配对

1. 在两台 Windows x64 电脑上运行完整发布包，进入「文件夹同步」，点击「启动同步服务」。每台电脑自动生成独立且持久的设备 ID，可自行设置电脑名称。
2. 在「电脑设备 → 添加电脑」中填入对方设备 ID；两台电脑都需要互相添加。连接地址默认 `dynamic`，也支持 `tcp://192.168.1.20:22000`，多个地址用逗号分隔。
3. 第一台电脑添加本机文件夹、选择需要共享的电脑，保存并复制共享 ID。
4. 第二台电脑添加自己的本机文件夹，填入相同共享 ID，选择第一台电脑。两台电脑的本地路径可以不同；首次同步会合并双方已有内容。
5. 默认「自动同步」，设备在线且文件夹启用后开始传输。系统防火墙弹窗出现时允许同步引擎联网。内网会尝试自动发现，外网使用直连或公共中继，实际连通性受网络环境影响。

### 已有 Tailscale 网络

在「添加电脑 / 编辑电脑」自行填写或选择同步对象，无需预设某一台电脑：

| 字段 | 填写内容 |
| --- | --- |
| 设备 ID | 对方**同步程序**显示的完整 ID，作为身份校验值 |
| 电脑名称 | 自定义名称，用于区分电脑 |
| 连接地址 | 对方 Tailscale IP（如 `100.101.102.103`）或 MagicDNS 名称；自动补成 `tcp://地址:22000` |
| 自定义端口 | 填写 `主机:端口` 或 `tcp://主机:端口`；IPv6 带端口使用 `[IPv6]:端口` |

可点击「读取 Tailscale 设备」并从下拉列表手动选择。读取不会覆盖已填内容或自动选定目标，选择后才会填入地址；设备 ID 仍需自行粘贴。也可完全手动输入，不必读取组网列表。本机身份栏支持读取和复制本机 Tailscale IP。

双方需要开启 Tailscale 和同步程序；Tailscale 网络访问规则、系统防火墙允许 TCP 22000（或自定义同步端口）。组网在线与同步服务在线是两个状态，对方只开启 Tailscale 时不会显示同步已完成。固定地址只用于主动连接到所填地址；手动额外加入 `dynamic` 可保留自动发现。程序不会更改 Tailscale 登录、网络策略或系统防火墙。

Mac / Linux 电脑可使用官方 Syncthing：在其管理界面添加此 Windows 电脑的设备 ID 与 Tailscale 地址，再添加对应共享 ID 的文件夹。Windows 发布包面向 Windows x64；跨系统通过同步协议互通。

连接地址格式参考 [Syncthing 配置文档](https://docs.syncthing.net/users/config)，MagicDNS 名称参考 [Tailscale 文档](https://tailscale.com/docs/features/magicdns)。

### 同步方式

- **自动同步**：监听文件变化，通常几秒后同步；每小时补充扫描。
- **手动同步**：平时暂停，点击「立即同步」执行扫描与传输，确认所有共享电脑完成本轮后自动暂停。对方也需启用对应文件夹；离线或尚未配对时保持等待，不以本机扫描结束冒充传输完成。
- **间隔定时 / 每天定时**：按 1～10080 分钟间隔或本机每天指定时间触发。计划持久保存，休眠或重启后补执行错过的一轮，完成后暂停。两边都使用定时时建议安排相同时间；接收端可保持自动模式。
- **暂停**：暂停此目录和定时任务；「立即同步」恢复原模式。停止服务会停止全部同步。退出时中断的手动任务下次保持暂停，定时任务按已保存计划恢复。

支持双向、仅发送、仅接收。双向模式会传播文件删除。来自其他电脑的覆盖或删除会由 Syncthing 的 staggered 版本控制保留到本地 `.stversions`，约保留 30 天；本机主动删除的文件依靠其他电脑的历史版本保留。并发编辑保留 `sync-conflict` 副本。版本文件占用磁盘空间；恢复旧文件时先暂停同步，从 `.stversions` 复制回原路径，再恢复同步。详见 [官方版本控制说明](https://docs.syncthing.net/users/versioning.html)。

勾选「关闭窗口后在托盘继续同步」可后台运行，从托盘右键退出才会结束同步服务。勾选「下次打开工具箱时启动同步」会随工具箱启动恢复服务；本版不创建 Windows 开机启动项。执行自动和定时任务需要工具箱运行，电脑之间同时在线时交换文件。

设备证书、索引和配置保存在 `%APPDATA%/Omini工具箱/sync/`，与系统已有 Syncthing 配置隔离。每台电脑自动生成自身身份；发布包不包含个人证书或配置，分发时使用完整发布包。移除设备或文件夹只移除共享配置，保留本机文件。应用通过带随机 API 密钥的本地回环 REST 管理独立引擎，多窗口实例锁防止争用同一配置。

开发环境获取引擎：`python scripts/fetch_syncthing.py`；脚本下载固定官方版本并校验发布方提供的 SHA-256，许可和来源随包保存在 `tools/syncthing-*`。`build.ps1` 已包含此步骤。

回归验证：`python -m unittest tests.test_folder_sync -v`。使用临时配置、仅本机直连的两台真实引擎测试双向传输、文件监听、删除与历史版本、并发冲突、手动完成暂停、设备身份重启恢复、定时补执行、暂停与界面按钮；不会读取已有同步目录。

## 数据位置

配置、任务记录与日志保存在 `%APPDATA%/Omini工具箱/`。Cookie 文件只记录用户选定的本地路径，不复制 Cookie 内容；选择浏览器会话时，只由 yt-dlp 在本机读取对应浏览器数据。
