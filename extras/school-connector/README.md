# Omini 教务连接

Chrome / Edge 扩展。解压网页提供的 ZIP，在扩展管理中开启开发者模式，加载该文件夹。
在工具箱页面点击扩展图标并连接，完成学校登录后返回工具箱。

连接只针对用户点击时的工具箱标签页及其来源；只请求学校教务域名的 Cookie 权限。
Cookie 在内存中传递，不写入扩展存储。工具箱退出账号或重新加载页面后清除内存会话。
重新加载页面后，需要再次点击扩展连接。表格或 HAR / JSON 导入不依赖扩展。

源文件更新后运行 `python scripts/package_school_connector.py` 更新网页下载包。

1.1.0：在官方网页自动加载连接桥；本机连接页通过点击扩展按钮连接。网页点击学校登录即可接入；在学校标签页确认已登录并读取课表，再自动导入工具箱。会话 Cookie 与课表响应只在内存中传递。关闭导入窗口会取消连接。已装 1.0.0 的浏览器需替换扩展目录并重新加载，然后刷新工具箱网页。
