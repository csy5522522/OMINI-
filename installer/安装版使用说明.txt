Omini工具箱 1.1.6 · Windows 安装版

安装与启动
双击 Omini-Toolbox-1.1.6-Setup.exe，选择安装目录后点击安装。
安装会自动放置完整程序、依赖和同步引擎。
安装完成后从开始菜单或桌面快捷方式运行 Omini工具箱。

本机 FFmpeg 与 TXT 笔记
视频合并、M3U8 与音频转换使用本机 FFmpeg。请先安装并加入 PATH，或在「设置 → 本机 FFmpeg」选择 ffmpeg.exe 后保存。
侧栏「离线 TXT 笔记」支持自动保存和导入文本，可选择本机目录。删除的 TXT 移到所选目录的 .trash 文件夹。
学校网页、班级查询与 PDF 预览使用系统浏览器；个人课表支持 HAR 导入和粘贴 Cookie 在线刷新。
升级会清理旧版附带的浏览器运行库和 FFmpeg，个人数据保留。

AI 编程助手
侧栏「AI 编程助手」分别配置 Codex、Gemini CLI、Antigravity 反重力、Claude Code 的代理环境。
默认代理地址 http://127.0.0.1:7890；检测程序并保存后，可测试网络和带代理启动。
Codex 标签支持 CLI / 桌面版；代理变更后请正常退出已有客户端，再从本页启动。
「Codex 成员账号池」启动本地服务，逐个浏览器登录成员或导入 Codex OAuth JSON，选择模型后启动 Codex。
账号池默认让新会话轮询分配，同一会话保持账号；也可按请求轮询或优先使用首个可用账号。
账号池专用配置与会话在 %APPDATA%/Omini工具箱/ai-assistants/codex-pool/，原有配置和会话保留。
个人凭据保存在用户目录，完整退出工具箱时停止账号池服务。

Omini API
打开侧栏「Omini API」，即可使用 Codex 注册、网站搜索、号池账号、号池网站、Claude 独立、设置与分组和日志。
本机已有 Desktop/Omini Open Ai/Omini API 时继续使用原账号和配置；也可点击「选择目录」选择原工具目录。
新电脑的数据默认保存在 %APPDATA%/Omini工具箱/omini-api/。
切换侧栏后 API 任务继续运行；退出工具箱时保存配置并停止 API 子进程。

多电脑文件夹同步
1. 两台电脑都启动同步程序。
2. 打开「文件夹同步」，点击「启动同步服务」。
3. 在「电脑设备」中互相添加对方同步程序显示的设备 ID。
4. Tailscale 用户可自行填写对方 Tailscale IP 或 MagicDNS 名称，默认补齐端口 22000；也可读取设备列表后选择。
5. 两边添加本机文件夹，填写相同的共享 ID，勾选对方电脑。
6. 可选择自动同步、手动同步、间隔定时或每天定时。

执行同步时需保持程序运行。勾选托盘后台后，关闭窗口仍会同步；右键托盘「退出工具箱」结束。
双向模式会传播修改和删除。远程覆盖/删除的历史文件保留在同步目录的 .stversions 中，约保留30天。
并发修改保留 sync-conflict 冲突副本。

升级与卸载
可在「设置 → 软件更新」点击检查更新，下载并校验新版后选择「退出并安装更新」。
私有 GitHub 仓库需要填写可访问该仓库且具有 Contents 只读权限的 Token，可勾选 Windows 本机加密保存。
升级前从系统托盘退出工具箱，再运行新版本安装程序。
可在 Windows「设置 → 应用 → 已安装的应用」中卸载，也可从开始菜单选择卸载。
卸载只移除已安装的程序文件和快捷方式，保留个人设置和已同步文件。
设置与本机设备身份保存在 %APPDATA%/Omini工具箱/，重新安装会继续使用。

系统：Windows 10 / 11，x64 兼容处理器。
Mac / Linux 可使用 Syncthing 与此 Windows 程序配对同步。
