Omini工具箱 1.2.3 · Windows 安装版

安装与启动
双击 Omini工具箱-1.2.3-Setup.exe（正式发布附件为 Omini-Toolbox-1.2.3-Setup.exe），选择安装目录后点击安装。
安装会自动放置完整程序、依赖和同步引擎。
安装完成后从开始菜单或桌面快捷方式运行 Omini工具箱。

邮箱账号与网页端
点击侧栏「邮箱注册 / 登录」，或进入「设置 → 邮箱账号与网页端」。
默认服务地址 https://my.omini.cn，点击「连接官方云端」可切回官方服务。
填写邮箱、密码和注册确认密码，点击「邮箱注册」或「邮箱登录」。
点击「打开网页端」可在浏览器使用同一邮箱账号。邮箱为账号标识，本版未接入验证码。
Windows 本机加密可记住会话，密码不保存。网页会话有效期 12 小时；桌面勾选记住登录后有效期 30 天，启动验证有效凭据时续期。
自建服务可填写其完整地址；本机服务地址填写 http://127.0.0.1:18765 后点击「启动本机网页服务」。
同账号多个客户端与网页同步课表、备忘录、主题与功能偏好、助手配置和 Codex 成员池。
账号工作区每 15 秒同步，备忘录每 20 秒同步；可点击「立即同步全部账号数据」。
离线修改保存在当前账号目录；「同步备份与恢复」可恢复发生冲突的字段。
新增账号工作区同步需配合 1.2.3 服务端，自建服务请同步更新代码或镜像。

超级备忘录
左侧管理笔记，右侧只有一个正文区，文字与图片直接编辑，不再上下重复显示。
底部图标可插入图片，「更多」包含立即保存、历史版本、TXT 导入、另存为、重命名与移到回收站。
目录管理与导入本机备忘录位于左栏底部的工作区菜单，Ctrl+S 可立即保存。
支持文字与图片、自动保存、搜索、TXT 导入导出、历史动作版本、回收站和回滚。
输入会自动保存到本机，登录后每 20 秒同步，或点击「立即同步」。
每次保存、重命名、删除和回滚保留历史；回滚创建新版本，原历史继续保留。
离线编辑稍后上传，云端发生并发修改时生成冲突副本，避免覆盖。
图片支持插入和粘贴，PNG/JPEG/GIF/WebP 最多 10 MB，正文每篇最多 2 MB。
首次关联的账号登录时自动合并本机笔记、图片、全部历史和回收站，保留本机加密文件；重复登录只合并新增动作，其他账号继续隔离。
工作区菜单中的「导入本机备忘录」可手动合并其他目录，保留真实标题与历史。

可选功能加载
进入桌面「设置 → 可选功能加载」，勾选所需功能并点击「保存设置」。
取消勾选立即隐藏对应侧栏并停止该功能后台任务；下载会暂停，个人数据继续保留。
重新勾选即可恢复。全部关闭时设置和邮箱账号仍可使用，重启后恢复已保存选择。
网页「偏好设置」也可勾选下载中心、学校课表、超级备忘录和 AI 编程助手；登录后功能选择随账号同步。

本机 FFmpeg 与 TXT 笔记
视频合并、M3U8 与音频转换使用本机 FFmpeg。「设置 → 可选组件 · 下载安装」可安装 FFmpeg 和 CLIProxyAPI。
下载安装支持校验 SHA-256 与取消；FFmpeg 成功后自动配置路径。也可在「本机 FFmpeg」手动选择程序。
侧栏「超级备忘录」支持自动保存、图片、账号同步及版本回滚，旧 TXT 迁移时保留加密恢复副本。
学校网页、班级查询与 PDF 预览使用系统浏览器；个人课表支持 HAR 导入和粘贴 Cookie 在线刷新。
升级会清理旧版附带的浏览器运行库和 FFmpeg，个人数据保留。

AI 编程助手
侧栏「AI 编程助手」分别配置 Codex、Gemini CLI、Antigravity 反重力、Claude Code 的代理环境。
默认代理地址 http://127.0.0.1:7890；检测程序并保存后，可测试网络和带代理启动。
Codex 标签支持 CLI / 桌面版；代理变更后请正常退出已有客户端，再从本页启动。
「Codex 成员账号池」启动本地服务，逐个浏览器登录成员或导入 Codex OAuth JSON，选择模型后启动 Codex。
账号池调度支持会话轮询、雨露均沾、优先账号和加权轮询；可设置成员优先级与权重，运行中保存并应用。
「查询所选额度 / 查询全部额度」显示 5 小时、周剩余百分比和重置时间，悬停查看查询时间或错误。
雨露均沾按请求均分并关闭会话保持；请求数量相同时，额度消耗可能不同。
未登录时账号池配置位于 %APPDATA%/Omini工具箱/ai-assistants/；登录后使用 account-workspaces/ 下的独立账号目录。
Codex 成员凭据、状态与调度随账号同步；程序路径、下载目录、FFmpeg、本地服务端口和密钥按设备保留。
个人凭据保存在用户目录，完整退出工具箱时停止账号池服务。
停服时仍显示本地成员；额度、模型、所选成员和标签会保存并在重启后恢复。
上次运行中的账号池可随工具箱恢复；手动停止后保持停止，可取消自动恢复选项。
「操作记录」带时间保存配置、调度、成员、额度查询、服务启停和助手启动动作，可导出全部记录 TXT。
配置、状态和记录在对应工作区加密保存，配置保留 .bak，成员变更前自动加密备份。
升级和卸载保留个人数据。旧版仅在内存的操作日志没有历史文件，本版开始持续保存后续记录。

多电脑文件夹同步
1. 两台电脑都启动同步程序。
2. 打开「文件夹同步」，点击「启动同步服务」。
3. 在「电脑设备」中互相添加对方同步程序显示的设备 ID。
4. Tailscale 用户可自行填写对方 Tailscale IP 或 MagicDNS 名称，默认补齐端口 22000；也可读取设备列表后选择。
5. 两边添加本机文件夹，填写相同的共享 ID，勾选对方电脑。
6. 可选择自动同步、手动同步、间隔定时或每天定时。

执行同步时需保持程序运行。勾选托盘后台后，关闭窗口仍会同步；右键托盘「退出工具箱」结束。
双向模式会传播修改和删除。远程覆盖/删除的历史文件保留在同步目录的 .stversions 中，约保留30天。
并发修改保留 sync-conflict 冲突副本。

升级与卸载
可在「设置 → 软件更新」点击检查更新，下载并校验新版后选择「退出并安装更新」。
私有 GitHub 仓库需要填写可访问该仓库且具有 Contents 只读权限的 Token，可勾选 Windows 本机加密保存。
升级前从系统托盘退出工具箱，再运行新版本安装程序。
可在 Windows「设置 → 应用 → 已安装的应用」中卸载，也可从开始菜单选择卸载。
卸载只移除已安装的程序文件和快捷方式，保留个人设置和已同步文件。
设置与本机设备身份保存在 %APPDATA%/Omini工具箱/，重新安装会继续使用。

系统：Windows 10 / 11，x64 兼容处理器。
Mac / Linux 可使用 Syncthing 与此 Windows 程序配对同步。

1.2.3 更新说明
课表选定周次会自动保存，同账号桌面与网页同步，包含全学期视图。
超级备忘录的标题、正文、图片、历史和本机缓存已增加存储加密。
旧笔记先产生加密恢复副本，再迁移为 .ominote 密文；通过工具箱阅读，另存为 TXT 仍输出普通文本。
Windows 本机密钥由当前用户 DPAPI 保护；备份需复制整个笔记目录（含隐藏数据库与密钥）。更换电脑前在原电脑导出。
这是存储加密，服务器运行时可解密以支持同步。此前导出文件及旧备份仍按原格式保存。
桌面删除 Omini API、Bright Data；Web 删除下载中心。桌面下载仍保留。
修复长期运行内存增长及抖音分享播放地址 404 回退。

1.2.3 修复：首次关联账号登录时自动合并本机备忘录、图片及全部历史；凭据过期保留账号工作区，重新登录后继续同步。勾选记住登录后有效期 30 天，启动验证有效凭据时续期。原本机文件保留，其他账号隔离。
