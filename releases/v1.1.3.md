## Omini工具箱 1.1.3

下载 **Omini-Toolbox-1.1.3-Setup.exe**，运行安装向导即可安装或升级。程序运行无需另装 Python，升级保留个人设置、同步设备及已有文件。

### 新增 Omini API

- 桌面侧栏新增「Omini API」，完整接入 Codex 注册、网站搜索、号池账号、号池网站、Claude 独立、设置与分组、日志七个页面。
- 保留账号注册、邮箱验证、Key 与分组管理、余额查询与自动轮换、OpenAI / Claude 本地代理。
- 可直接使用原工具的数据目录，也可选择新目录。已有账号和配置继续保存在所选目录中。
- 首次进入时启动，切换侧栏后任务继续运行。浅色和深色主题随工具箱切换，退出时保存配置并停止 API 进程。

### 版本管理

- 程序与安装包统一读取源码版本 `1.1.3`。
- 源码通过 Git 提交和 `v1.1.3` 标签保存，保留此前版本和提交历史。
- 安装包随附 SHA-256 文件，支持现有工具箱「设置 → 软件更新」检查和下载安装。
- 源码与安装包均排除个人账号、邮箱服务凭据及本机运行记录。

本机已有 `Desktop/Omini Open Ai/Omini API` 目录时，首次使用会读取该目录；其他位置可点击「选择目录」。新电脑默认使用 `%APPDATA%/Omini工具箱/omini-api/`。

44 项回归测试全部通过，覆盖 Omini API 接口与代理及现有下载、备忘录和更新功能。已验证安装后 EXE 的七页载入、主题切换、侧栏切换、后台余额查询和退出保存，并验证安装、覆盖升级、卸载及个人数据保留。
