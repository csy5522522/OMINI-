# Omini工具箱 1.1.4

- 新增 AI 编程助手侧栏：Codex、Gemini CLI、Antigravity 反重力、Claude Code 独立代理配置、网络检查与启动。
- 新增 Codex 成员账号池，支持浏览器逐个登录、导入 OAuth JSON、启停成员、读取模型、轮询和会话保持。
- Codex 桌面版与 CLI 使用独立配置目录接入本地账号池，保留原有登录和会话目录。
- 固定 CLIProxyAPI v8.0.35 并校验 SHA-256，服务仅本机开放，配置及本地密钥由 Windows DPAPI 加密。

首次使用：侧栏「AI 编程助手」设置代理和程序；账号池页面启动服务并添加成员，读取模型后启动 Codex。

个人数据保存在 `%APPDATA%/Omini工具箱/`，升级时继续保留。
