# Omini工具箱 1.1.6

备忘录改为离线 TXT 笔记，安装包移除内置浏览器核心和 FFmpeg。

Windows x64 安装包约 **133.6 MiB**，比本地 1.1.5 构建减少约 **40%**。下载安装包运行即可覆盖升级。

- TXT 支持自动保存、Ctrl+S、搜索、重命名、导入、另存为和自选目录；保存时检测外部编辑冲突。
- 学校登录、班级课表、PDF 预览使用系统默认浏览器；个人课表继续支持 HAR 导入和 Cookie 在线刷新。
- 视频合并、M3U8 和音频转换使用本机 FFmpeg。请安装并加入 PATH，或到「设置 → 本机 FFmpeg」选择 ffmpeg.exe 后保存。
- 覆盖升级清理旧版附带的浏览器运行库与 FFmpeg。个人设置、旧版备忘录缓存和已下载文件保留。
- 新增 AI 编程助手，为 Codex 桌面版 / CLI、Gemini CLI、Antigravity、Claude Code 分别配置代理环境和启动入口。
- 新增 Codex 成员账号池，支持逐个登录或导入账号、启停成员、新会话轮询和同一会话保持账号；支持桌面版和 CLI 通过专用配置接入。

已通过实际 EXE 的 TXT 保存、课表浏览器入口、AI 账号池、Omini API、媒体转换与 HLS 下载检查，并验证安装、覆盖升级、卸载时个人数据保留。

安装包附带 `.sha256` 校验文件；已有用户也可通过「设置 → 软件更新」检查本次更新。
