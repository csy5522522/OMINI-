# Omini工具箱 1.2.1

- 超级备忘录改为统一文档工作台：左侧列表、右侧单一正文区，文字与图片直接编辑，移除上下重复的编辑与预览卡片。
- 顶部成排按钮收进底部插图入口与「更多」菜单；保留 Ctrl+S、自动保存、撤销重做、TXT 导入导出、历史回滚和回收站恢复。
- 同账号多个客户端与网页同步课表及学期日期、备忘录、主题及功能偏好、AI 助手连接配置、Codex 成员凭据/启停状态、调度/权重/模型、额度快照和操作记录。
- 服务端按账号隔离并加密同步文档、版本和冲突备份；支持离线草稿、离线重启、独立字段合并及冲突字段恢复。程序路径、安装目录与本地代理端口/密钥按设备保存。
- 网页新增 AI 编程助手成员管理；设置新增「立即同步全部账号数据」和「同步备份与恢复」。
- 桌面设置新增 FFmpeg、CLIProxyAPI 下载安装按钮，支持 SHA-256 校验、取消与失败重试；FFmpeg 安装成功自动配置路径。

已有客户端可在「设置 → 软件更新」检查并安装 1.2.1，或下载本页安装包覆盖升级。升级保留个人设置、笔记和成员数据。

新增账号工作区同步需配合本版本服务端。自建服务请更新服务代码/镜像并保留数据库与 `account-sync.key`；本次 GitHub 安装包发布与线上服务器部署分别进行。
