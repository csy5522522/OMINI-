# Omini工具箱 1.2.4

- AI 编程助手新增「成员账号 / API 池」，支持 Codex 登录成员与 API Key 线路混合管理，可添加、编辑、启停和移出线路。
- 支持 OpenAI Chat / 兼容接口、OpenAI Responses、Anthropic Messages、Gemini GenerateContent、Gemini Interactions、Vertex API Key、xAI Responses、Meta Responses 共 8 种协议。
- 支持模型 ID、`上游ID => 对外ID` 别名、线路代理、附加请求头、优先级与权重，运行中自动应用配置。
- 新增线路检查，读取模型列表、鉴权状态与耗时；「验证模型（少量用量）」单独发起小请求。上游未开放模型列表时可手动填写模型 ID。
- API Key 及附加请求头在桌面加密保存，随账号工作区加密同步；网页支持线路管理，检查与模型验证在桌面执行。
- 修复备忘录同步与本机导入的并发问题，优化网页免登录浏览、静态资源缓存及按需加载。

升级前保存编辑并从托盘退出旧版，再运行安装包。安装和升级保留个人数据与登录缓存。自建同步服务请同步更新至 1.2.4，以支持 API 线路字段；旧版本标签和发布附件保留。
